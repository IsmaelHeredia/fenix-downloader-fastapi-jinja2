Ayuda

Uso básico

  • Links — pegá una o varias URLs de YouTube (una por línea) y descargalas como MP3 o MP4.
  • Buscar — escribí nombres de canciones; se busca en YouTube y se descarga el mejor resultado en MP3.
  • Playlist — pegá el link de una lista de reproducción y descargala completa, como canciones o como videos.
  • Exportar — extrae los links de una playlist a un archivo .txt, sin descargar nada.
  • Convertir — indicá la ruta local de un MP4/MKV/etc. y convertilo a MP3 (no borra el archivo original).

Opciones de descarga

  • Calidad — 720p, 1080p (recomendado) o Máxima calidad, que evita AV1 cuando es posible.
  • Doblaje ES — usa la pista de audio en español si YouTube la ofrece para ese video.
  • Subtítulos ES — incluye subtítulos oficiales o automáticos en español, si existen (con respaldo a inglés).
  • Usar cookies — activa tu sesión de YouTube para evitar bloqueos por edad o límite de solicitudes. Ver detalle más abajo.

yt-dlp y YouTube

yt-dlp cambia seguido porque YouTube cambia seguido de su lado. Si empezás a ver errores de extracción "raros", lo primero que hay que probar es actualizar: 

pip install -U "yt-dlp[default]" yt-dlp-ejs
pip install -U "curl_cffi>=0.10"

Dependencias del sistema

YouTube moderno exige un runtime de JavaScript para poder extraer los videos. Deno es el recomendado (mín. 2.3): 

# Linux / macOS
curl -fsSL https://deno.land/install.sh | sh
# Reiniciá la terminal y el servidor de la app

# Comprobar la instalación
which deno && deno --version
yt-dlp --list-impersonate-targets
yt-dlp -v -f "bv*+ba/b" "https://www.youtube.com/watch?v=dQw4w9WgXcQ"

Alternativa: Node.js ≥ 22, seteando la variable de entorno YTDLP_JS_RUNTIME=node. También necesitás FFmpeg y FFprobe disponibles en el PATH del sistema (se usan para las conversiones a MP3/MP4 y para insertar subtítulos).

Cookies de YouTube

Activá el checkbox Usar cookies en el formulario para usarlas en esa descarga. Si no encuentra un archivo válido, la app te avisa en la consola y continúa sin cookies.

Archivo cookies.txt (recomendado en servidor)

  1. Entrá a YouTube logueado en el navegador.
  2. Usá una extensión tipo Get cookies.txt LOCALLY → exportá youtube.com en formato Netscape.
  3. Guardá el archivo como data/cookies.txt.

También podés indicar la ruta con la variable de entorno YTDLP_COOKIES_FILE, o usar las cookies directamente desde el navegador con YTDLP_COOKIES_FROM_BROWSER.
